# Malice & Mortar

An idle game of cheerful villainy. Start as a damp imp in a hole, hire minions, conquer the neighbours, and grow into an overlord with a castle of unreasonable size.

Play it: https://kmortensenf.github.io/malice-and-mortar/

## Files

- `malice-and-mortar.html` is the game source: one file with the styles, markup and script.
- `index.html` is the website, built from the source.
- `build.js` rebuilds `index.html` after the source changes: `node build.js`.

Everything runs in the browser. Graphics are drawn on a canvas and the music and sound effects are synthesised, so there are no asset files.
